# Smart Parking Management System
**Assignment 4 (Milestone 2)**

### Реализованные технологии:
- **Database**: Supabase (PostgreSQL)
- **Generics**: Универсальный класс `ListResult<T>`
- **Design Patterns**: 
  - Factory Method (для создания мест)
  - Builder (для сессий парковки)
  - Singleton (для тарифов)
